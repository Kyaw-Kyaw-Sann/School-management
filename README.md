# School Management Demo

A small front-end demonstration of second-year school activities: a timetable, roll call, library book selection, exam results, a demo login, and account records.

## Run locally

Open `index.html` in a modern web browser. No installation, server, or external dependencies are required.

## Publish with GitHub Pages

Push this folder to a GitHub repository, then open **Settings → Pages** and deploy from the `main` branch using the repository root. GitHub Pages will use `index.html` as the home page.

## Note

This is a client-side learning demonstration. Its login and result-update password are not real authentication and must not be used to protect real student data.
